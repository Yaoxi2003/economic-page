# E-commerce Product Page

## Overview
This is a high-performance, responsive product detail page designed for a seamless shopping experience. The project focuses on complex UI interactions, such as an integrated lightbox gallery and a state-managed shopping cart. While the visual design and image assets are courtesy of Frontend Mentor, I engineered the entire solution from the ground up, focusing on clean code and intuitive user flows.

## Functionality
The application provides a robust set of features typical of modern e-commerce platforms:

Dynamic Lightbox Gallery: An immersive, full-screen modal gallery triggered by clicking the primary product image.

Thumbnail Navigation: Users can switch the main product view by interacting with thumbnail images for a detailed look at different angles.

Interactive Shopping Cart: * Quantity increment/decrement controls.

"Add to Cart" functionality with real-time feedback.

A persistent cart dropdown to view, manage, or remove items.

Responsive Architecture: A mobile-first design that adapts the layout—including navigation menus and image sliders—across all screen sizes.

Interactive UI Feedback: Hand-coded hover, active, and focus states for all buttons, links, and selection states to improve usability.
